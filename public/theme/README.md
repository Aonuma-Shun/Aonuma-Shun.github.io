# Theme assets

- `icons.svg`: Sun and Moon from Lucide v1.8.0, ISC license in `LICENSE-lucide.txt`.
- `beatrice-cameo.webp`, `bernkastel-cameo.webp`, `lambdadelta-cameo.webp`: small transparent versions of character sprites already used in the user's Edge start-page project. Artwork belongs to its respective owners.

The Sakutarou plush outline is drawn inline in `src/SiteAtmosphere.tsx`, referencing the [Episode 4 plush CG](https://canmom.art/img/embed/umineko/ep4/045-premium-sakutaro.png). It preserves the pointed ears, oval eyes, double muzzle, long body and scarf, with the pose rotated upright. The reference is not shipped or fetched by the site. Its colors and opacity adapt to the dark and light themes.

The three character cameos are distributed across the interest cards, outside the text flow. No external fonts, remote image requests, video or animation libraries are added.
